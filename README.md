\# BCI Epilepsy Monitoring System



Brain-Computer Interface system for real-time epilepsy monitoring using EEG, EMG, EOG, and ECG signals.



\## Hardware Components

\- Neuphony EXG Synapse

\- Arduino Mega 2560

\- ESP32 microcontroller

\- DHT11 temperature sensor



\## Installation



\- ML Interface: `python software/python/ml\_models/main.py`

\- Visualization: `python software/python/visualization/real\_time\_plotter.py`
